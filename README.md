# Requirements

[NodeJS v24.13.1<](https://nodejs.org/en/download)

## Getting Started

First, install the deppendencies using:

```bash
npm i
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
